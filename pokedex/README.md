# Pokédex

A React application for exploring Pokémon data through a simple and responsive interface.

## Features

- Browse Pokémon information
- React-based user interface
- Fast development with Vite and Hot Module Replacement
- Code quality checks with Oxlint
- Production-ready build configuration

## Technologies

- [React](https://react.dev/)
- [Vite](https://vite.dev/)
- [Oxlint](https://oxc.rs/)
- JavaScript

## Getting started

### Prerequisites

- Node.js 18 or newer
- npm
